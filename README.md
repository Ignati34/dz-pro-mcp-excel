# ДЗ Pro — AI-помощник по заявкам через Excel MCP

Отдельный локальный проект для Pro-части задания. Lite-проект погоды находится в соседней папке `mcp-weather-assistant`; это приложение запускается на порту **8001**, поэтому не заменяет погодный проект на `8000`.

Приложение написано на Python, FastAPI, официальном Python MCP SDK и OpenAI SDK. Модель выбирает действия в чате, а backend выполняет чтение и запись через готовый Excel MCP-сервер. Собственный MCP-сервер не создаётся; приложение не открывает `.xlsx` через `openpyxl`/`pandas`.

## Excel MCP-сервер

Используется [excel-mcp-server от haris-musa](https://github.com/haris-musa/excel-mcp-server), закреплённый на версии `2.3.3`. В этой версии проверено `initialize` и `tools/list`; сервер возвращает 46 инструментов. В приложении используются настоящие MCP-инструменты `create_workbook`, `read_range`, `write_range`; для диагностики также доступны `describe_workbook` и `list_workbooks`. Подробные схемы приведены в [TOOLS.md](https://github.com/haris-musa/excel-mcp-server/blob/main/TOOLS.md).

Соединение идёт через `stdio`. Сервер запускается с `--allow-dir <папка проекта>\data`, поэтому ему разрешён доступ только в `data`. Excel MCP запускается заново на каждое обращение. Его дочерний процесс получает минимально необходимое окружение и не наследует `OPENAI_API_KEY`.

Книга `data/requests.xlsx`, лист `Заявки`, создаётся через `create_workbook` и заполняется через `write_range`. В ней только вымышленные данные:

| ID | Клиент | Проблема | Статус |
|---:|---|---|---|
| 101 | Иван Петров | Ноутбук не включается | Новый |
| 102 | Мария Соколова | Принтер не печатает | В работе |
| 103 | Олег Иванов | Мерцает монитор | Готово |

При добавлении агент читает существующие ID, выбирает `max(ID) + 1`, записывает строку со статусом «Новый» и перечитывает книгу для проверки результата.

## Установка и запуск на Windows

Откройте PowerShell и выполните команды по очереди:

```powershell
Set-Location "E:\Univer_AI\Разработка AI-агентов на Codex\Тема 9. AI-агенты с инструментами API, интернет, MCP и внешние сервисы\DZ-Pro"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

В `.env` добавьте OpenAI API-ключ в строку `OPENAI_API_KEY=` и сохраните файл. Ключ хранится только локально; `.env` исключён из Git. Не отправляйте ключ в чат и не добавляйте его в README или снимки экрана. Для OpenAI-совместимого сервиса задайте его адрес в `OPENAI_BASE_URL` и выберите подходящую модель в `OPENAI_MODEL`.

Запустите Pro-приложение:

```powershell
.\run.ps1
```

Откройте [http://127.0.0.1:8001](http://127.0.0.1:8001). При первом обращении к Excel `uvx` скачает закреплённый MCP-пакет, поэтому первый запрос может выполняться дольше. Остановка — `Ctrl+C` в окне PowerShell.

Если команда активации окружения заблокирована политикой PowerShell, не активируйте его; запускайте напрямую:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8001
```

## Возможности и правила подтверждения

- Чат на русском, история отдельных UUID-сессий и кнопка «Новый диалог».
- Таблица справа читается через MCP `read_range`, обновляется кнопкой и после записи.
- Модель использует инструменты для показа и фильтрации заявок, добавления и предложения смены статуса.
- Смена статуса не записывается до нажатия «Подтвердить изменение». До этого backend сохраняет ID действия и сессии. Перед записью он заново читает заявку и проверяет ID, имя и прежний статус. После записи читает строку снова и подтверждает результат. Повторное нажатие не повторяет запись; «Отмена» не записывает изменения.
- Для неоднозначного имени агент просит ID. Неизвестный ID и неполные заявки не меняют Excel.
- Трассировка показывает фактическое имя MCP-инструмента, параметры, статус и результат или ошибку.

## Проверка сценариев

Для демонстрации выполните в чате:

1. «Добавь заявку от Анны Смирновой: ноутбук сильно тормозит». Должна появиться заявка №104 со статусом «Новый».
2. «Измени статус заявки Анны Смирновой на “В работе”». Проверьте предложение, нажмите подтверждение и обновите таблицу.
3. «Покажи все заявки, которые сейчас в работе». Должны отобразиться Мария Соколова и Анна Смирнова; помощник сообщает количество.
4. «Измени статус заявки №999 на “Готово”». Агент должен сообщить, что ID не найден, без записи.
5. «Добавь новую заявку от Дмитрия». Агент должен спросить описание проблемы и не вызывать запись.

Также проверьте отмену, повторное подтверждение, дубликаты имён и ситуацию, когда статус изменился до подтверждения. Для отчёта приложите скриншоты таблицы до и после операции и раскрытых трасс MCP. Используйте только приведённые вымышленные данные; не показывайте `.env`.

## Основные файлы

- `app.py` — FastAPI API и обработка сессий/подтверждений.
- `excel_agent.py` — бизнес-логика агента и безопасные действия.
- `mcp_client.py` — MCP клиент на `stdio`.
- `static/` — веб-интерфейс.
- `data/requests.xlsx` — демонстрационная книга, созданная через MCP.
- `.env.example` — список локальных настроек без секретов.
